# 星云智联（NebulaLink）常见故障自助排查手册

用户在申请售后寄修前，可按照本手册引导进行快速自助排查。约 70% 的蓝牙断连、单耳无声或充电异常问题可通过重置与清洁解决。

## 一、蓝牙连接失败 / 断连 / 单耳无声排查

### 1. NL-Pro2026 与 NL-Air3 恢复出厂设置（硬重置）
当出现左右耳无法配对、单边无声音、手机搜不到设备或触控失灵时，请按以下步骤重置：
1. 在手机蓝牙设置中点击“忽略此设备 / 取消配对”；
2. 将两只耳机放入充电盒中，**保持盒盖打开**（确保充电盒电量高于 20%）；
3. 长按充电盒背面/底部的**功能配对键 10 秒**；
4. 观察指示灯：**白灯快闪 3 次后转为红灯常亮 2 秒，随后熄灭并恢复白灯慢闪**，表示恢复出厂设置成功；
5. 合上盒盖等待 5 秒后重新开盖，使用手机蓝牙重新搜索配对即可。

### 2. NL-Studio（头戴式）硬重置与配对
1. 确保耳机处于开机状态，且未连接 3.5mm 或 USB-C 音频线；
2. 同时按住**“音量+”键与“电源/多功能键”保持 7 秒**；
3. 听到提示音且指示灯**红蓝交替快闪 3 次**后松手，配对列表已清空，重新连接即可。

### 3. 声音卡顿 / 频繁断连（尤其在地铁/机场）
- **原因**：启用了高码率编码（如 LDAC 990kbps 或 LHDC 5.0）在强射频干扰环境下容易丢包。
- **解决**：打开 NebulaLink App →「音质与连接」→ 将蓝牙编码切换为 **AAC** 或 **连接稳定性优先模式**，可显著改善卡顿。

## 二、充电异常 / 耳机放回充电盒仍不断连

1. **清洁金属触点**：长期佩戴后汗液或灰尘可能氧化遮挡充电盒底部的镀金顶针（Pogo Pin）。请使用干燥的无尘棉签蘸取少量 **75% 医用酒精**，轻轻擦拭耳机底部与充电盒内部的金属触点，晾干 **10 分钟**后再放入充电。
2. **检查充电盒电量**：若充电盒完全亏电（指示灯不亮），耳机放入后将无法触发霍尔开关关机，导致手机依然连接耳机。请使用原装 USB-C 线连接 5V 充电器充电 **30 分钟**以上激活。
3. **指示灯颜色含义速查**：
   - **绿灯常亮**：电量 80% - 100%（已充满）；
   - **橙灯/黄灯常亮**：电量 20% - 79%；
   - **红灯闪烁**：电量低于 20%（需及时充电）；
   - **红白交替快闪**：左右耳配对数据异常或触点接触不良，请执行上述硬重置操作。

## 三、降噪效果变差 / 通话对方听不清 / 啸叫声

1. **降噪深度不足（仅限 NL-Pro2026 / NL-Studio）**：
   - NL-Pro2026 用户请在 App 中运行「**耳塞贴合度测试**」，若提示漏气，请更换更大一号的硅胶耳塞（如从 M 号换为 L 号）。
   - 检查是否误触开启了「通透模式」或「风噪抑制模式」。
2. **戴上耳机出现高频啸叫声**：
   - 多为手掌遮挡了耳机外侧的前馈降噪麦克风开孔，或耳道内壁与出音嘴产生声学反馈，调整佩戴角度即可；若未遮挡仍持续啸叫，属于麦克风硬件故障，请直接申请售后换新。
3. **单耳进水后声音变小或无声**：
   - **切勿使用吹风机热风直吹**（高温会损坏振膜并融化防水胶）！
   - 请立即甩干表面水分，用吸水纸轻吸出音孔与麦克风孔，置于通风干燥处静置 **24 小时**后再试。若仍无声且在 NebulaCare+ 保障期内，可联系客服走意外进液保障通道。

## 四、单只补购后无法与旧耳机配对同步

若通过官方渠道单独补购了一只左耳、右耳或新充电盒，首次使用需强制同步双耳固件与配对密钥：
1. 将新旧两只耳机同时放入充电盒，合盖连接电源充电 **15 分钟**；
2. 开盖后长按充电盒功能键 **15 秒**（比普通重置多按 5 秒），直至指示灯转为**绿灯快闪 5 次**，即可完成双耳绑定。
