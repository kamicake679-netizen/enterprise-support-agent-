# 星云智联（NebulaLink）七天无理由退换货政策

为保障消费者权益并维护卫生安全标准，星云智联官方商城及授权线上旗舰店严格遵守国家《消费者权益保护法》及相关电商规范，制定本七天无理由退换货政策。

## 一、适用时效与计算标准

1. **7 天无理由退货期**：自物流信息显示用户**实际签收商品次日零时起算，满 168 小时（7 个自然日）**内，可申请七天无理由退货。
2. **15 天质量问题换货期**：自签收次日零时起 **15 个自然日**内，如经官方售后检测确认存在非人为硬件性能故障，可免费申请换货（更换同型号同颜色全新整机）或退货。

---

## 二、商品完好标准与拆封退货规则（重点条款）

由于入耳式/头戴式耳机属于贴身接触类电子产品，退货退款金额将根据商品是否拆封及外观完好程度判定：

1. **未拆封、塑封完整（全额退款）**：
   - 外包装透明塑封膜完好无破损，防伪标签未刮开，未激活使用，配件及赠品齐全，支持 **100% 全额退款**。

2. **已拆封但未激活/无外观划痕且无质量问题**：
   - 若用户已拆开外包装塑封膜，但耳机未与任何设备绑定激活、外观无任何划痕污渍、所有原装配件（含各尺寸备用耳塞、充电线、说明书）完整，且无质量问题申请无理由退货的：
   - **需扣除商品实付金额的 10% 作为整新与包装损耗费**（最低不少于 ¥30）。

3. **已拆封激活且无质量问题的退货（特殊说明）**：
   - 若耳机已拆封并完成蓝牙配对激活（NebulaLink App 或系统记录显示已绑定/使用），在外观无磕碰划痕、功能完好且配件齐全的前提下仍申请 7 天无理由退货的：
   - **需扣除商品实付金额的 15% 作为包装及卫生消杀损耗费**。
   - **不可退货情形**：若耳机表面存在明显划痕、跌落磕碰痕迹、进液受潮、耳塞/耳罩严重污损，或缺少核心配件（如缺失充电盒、单只耳机、原装耳罩），**不支持七天无理由退货**。

4. **赠品与套装处理**：
   - 随单附赠的实物赠品（如定制耳机保护壳、便携收纳包、支架等）需一并退回；若赠品已拆封使用或遗失，将按赠品标价从退款中扣除（耳机保护壳 ¥49，便携收纳包 ¥69）。

## 三、运费承担规则

| 退换货原因 | 寄回运费承担方 | 换新寄出运费承担方 |
| :--- | :--- | :--- |
| **非质量问题（7 天无理由退货）** | **用户自行承担**（建议选择顺丰或京东快递保价寄回，不支持到付） | 不适用 |
| **商品质量问题 / 发错货 / 运输破损** | **星云智联承担**（可申请官方上门取件，或用户先垫付后凭快递电子面单报销，上限 ¥20） | **星云智联承担** |
| **拒收快递（无质量问题）** | 退回运费及拦截费由用户承担（从退款中扣除 ¥15） | 不适用 |

## 四、退款时效与流程

1. **提交申请**：在签收 7 日内联系官方客服或订单页面提交退货申请，获取官方退货寄回地址与退货编码（RMA）。
2. **寄回与质检**：用户须在审核通过后 **3 个自然日**内寄出并回填快递单号；售后中心签收包裹后将在 **48 小时**内完成开箱质检（全程录像）。
3. **资金原路退回**：质检通过后，退款将在 **1-3 个工作日**内原路退回至用户原支付账户（微信/支付宝通常实时到账，信用卡/银行卡视发卡行需 1-5 个工作日）。

## 五、不适用七天无理由退货的特殊商品

- 官网“激光镌刻定制版”刻字耳机（除硬件质量问题外不支持无理由退换）；
- 单独购买的已拆封硅胶耳塞套、替换海绵耳罩等个人卫生耗材配件；
- 已超过签收 7 个自然日的订单（无质量问题）。
