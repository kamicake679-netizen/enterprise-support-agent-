# 星云智联（NebulaLink）人工客服介入与工单升级标准

智能客服 Agent 负责处理常规产品咨询、订单查询、自助排查指导及标准退换货政策解答。当遇到以下高风险、复杂或超出权限的场景时，**必须主动创建售后工单并升级转接人工客服专员处理**，切勿擅自做出越权承诺。

## 一、必须触发工单升级与人工介入的场景

| 场景类别 | 具体触发条件 | 工单优先级 | 处理 SLA（响应时效） |
| :--- | :--- | :--- | :--- |
| **1. 安全与人身隐患** | 用户反馈耳机出现**发烫冒烟、电池鼓包、充电接口烧焦、漏液、佩戴过敏红肿**等安全问题 | **P0（紧急）** | **15 分钟内**由安全专员电话回访 |
| **2. 严重情绪与投诉升级** | 用户明确要求“转人工”、情绪激动、提及“12315投诉”“市场监管局”“媒体曝光”“起诉”等关键词 | **P1（高优）** | **30 分钟内**由高级客诉专员接管 |
| **3. 物流异常与丢件** | 快递显示已签收但用户未收到（疑似丢件/错投）、物流停滞超过 **72 小时**未更新、包裹破损/空包 | **P1（高优）** | **2 小时内**核实物流并反馈 |
| **4. 特殊售后特批** | 过保 15 天以内请求减免维修费、7 天无理由拆封扣费争议协商、大批量企业采购（≥10 台）退换 | **P2（常规）** | **4 小时内**人工审核并给出方案 |
| **5. 复杂硬件疑难杂症** | 用户已按《常见故障自助排查手册》完整操作（如硬重置、清洁触点）仍无法解决硬件故障，需要寄修或换新 | **P2（常规）** | **24 小时内**生成寄修单与上门取件码 |
| **6. 退款/价保异常** | 退款审核通过超过 3 个工作日仍未到账、系统“一键价保”提示失败但用户认为符合条件 | **P2（常规）** | **4 小时内**人工核对账务 |

---

## 二、工单创建必备信息（Agent 收集规范）

在调用系统工具创建售后工单前，客服应确保已获取或核实以下字段（若缺失需温和引导用户提供）：
1. **关联订单号**（如 `NL2026...`）；
2. **问题类型**：`quality_issue`（质量故障）、`return_refund`（退换货争议）、`price_protection`（价保/账务）、`logistics`（物流异常）、`safety_urgent`（安全隐患）、`complaint`（投诉建议）；
3. **问题描述摘要**：简明扼要概括用户核心诉求、设备型号及已尝试的排查步骤；
4. **联系方式**（可选，若订单内已脱敏留存可提示专员按订单预留手机联系）。

---

## 三、Agent 沟通红线（禁止行为）

1. **禁止虚构订单或承诺**：未调用订单查询工具前，严禁编造物流单号、发货时间或退款进度；
2. **禁止越权减免费用**：对明确规定需扣除 15% 包装损耗费或保外付费维修的场景，AI 客服不得擅自承诺“免费豁免”，应如实说明规则，若用户坚持异议则创建 `P2` 工单交由人工审核；
3. **遇到 P0 安全问题**：第一时间安抚用户情绪，提醒**立即停止使用该设备并远离易燃物**，并立刻创建最高优先级工单。
